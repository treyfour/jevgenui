# Reference frames

Key frames from a 17s screen recording of an "Operator" GenUI demo built on Jev.
Use these for **structure and interaction only**: layout, information hierarchy,
states, and behaviors. The visual skin (color, type, background) is our own.

| Frame | Time | What it shows |
|---|---|---|
| `01-empty-state.jpg` | 0.5s | Panel header, tagline, suggested-question chips, composer |
| `02-loading.jpg` | 3.0s | User bubble + "Asking Jev what to build" status |
| `03-breakdown-card.jpg` | 5.0s | Breakdown card: stacked bar, legend rows with count + %, summary line, Save row, follow-up chips |
| `04-linked-hover.jpg` | 7.0s | Hovering a legend row highlights its bar segment and dims the rest |
| `05-thought-process.jpg` | 11.0s | Expanded "Thought process": 7 rows (question, answer, confidence meter, %), latency + cost footer |
| `06-distribution.jpg` | 13.0s | One row expanded to its full probability distribution |
| `07-override.jpg` | 15.0s | User picked an alternative: row marked "You", card and summary re-render |
| `08-ranking-card.jpg` | 16.8s | Ranking card (horizontal bars) after override, follow-up chips |
